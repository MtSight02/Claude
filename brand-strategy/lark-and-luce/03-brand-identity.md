# Lark & Luce · 03 品牌视觉识别

> 核心视觉概念：**"Bone & First Light"**——骨白色的清晨画布上，只有一点点光。所有视觉决定都服务于"安静、留白、像比实际贵"。

## 1. Logo 三个方向

### 方向 A：Wordmark「Dawn Line」（推荐）

| 项目 | 说明 |
|---|---|
| 字体 | **Cormorant Garamond Light / Cormorant Light**（Google 免费），字距 +40 至 +60；付费替代：**Canela Light**（Commercial Type）或 **Romie**（价格与授权未核实） |
| 字形 | 全大写 `LARK & LUCE`，"&" 使用 Cormorant Italic 的花式 & 并缩小 85%，略高于基线 |
| 图形 | Wordmark 正下方一条 0.5pt 细横线，代表"地平线"；横线中心有一个 4px 的小菱形（烟花切的光点） |
| 布局 | 居中对称；横排为主，竖排（LARK / & / LUCE 三行）用于包装盒盖 |
| 为什么 | 最"quiet luxury"，像欧洲香氛或护肤品牌；横线 + 光点把"第一缕光"可视化而不幼稚；小尺寸下（网站 header、封签）依然清晰 |

### 方向 B：Monogram「L&L Sunrise」

| 项目 | 说明 |
|---|---|
| 字体 | 字标用 **Italiana**（Google 免费）；Monogram 为定制 |
| 图形 | 两个镜像的 "L" 构成一个半圆弧——像太阳从地平线升起；"&" 放在弧心 |
| 布局 | Monogram 单独用于社媒头像、封签、绒袋烫印；完整 Logo 为 Monogram 左 + 文字右 |
| 为什么 | 社媒头像识别度高；适合做烫金封签，开箱时有"徽章感" |
| 风险 | 定制图形需要设计师 3–5 轮，预算多 $200–400（估算）；两个 L 镜像可能被误读为 "LL" 而非 L&L |

### 方向 C：Lark Mark「The Single Feather」

| 项目 | 说明 |
|---|---|
| 字体 | **EB Garamond Regular** 小号大写 + **Jost Light** 副标 "EST. 2027 · LIGHT, LIGHTLY WORN" |
| 图形 | 极简线描的一根云雀羽毛（单线，3–4 笔），或一只飞翔的云雀剪影（仅 6–8 个节点） |
| 布局 | 图形在上，文字在下，竖排 |
| 为什么 | 鸟的形象让 "Lark" 成为主记忆点，弱化 "Luce" 发音问题 |
| 风险 | 鸟/羽毛在首饰与生活方式品牌中很常见，容易显得"平价礼品店"；商标显著性弱 |

**建议：** 主 Logo 用 A，配合 B 的 Monogram 作为社媒头像与封签（二者统一使用 Cormorant 体系）。C 作为备选，若商标检索发现 "Lark" 字样过于拥挤，可以用独特图形标增加显著性。

## 2. 色彩系统

| 名称 | HEX | 用途 | 使用比例 |
|---|---|---|---:|
| **Bone** | `#F3EFE8` | 网站背景、包装盒主色、摄影背景纸 | 60% |
| **Graphite** | `#2B2B2B` | 主文字、Logo、按钮、页脚 | 20% |
| **Stone** | `#A39E93` | 次要文字、分隔线、图标、价格旁的说明文字 | 10% |
| **Dawn** | `#E8C9B5` | 柔和强调：标签、Hover、新品角标、邮件 Banner 背景 | 7% |
| **Gilt** | `#B89B5E` | 金属点缀：烫金、Logo 横线上的光点、星级评分 | 3% |
| *Mist（补充）* | `#E4DED4` | 卡片底色、表单输入框、第二层背景（Bone 的深一档） | 按需（计入 Bone 60% 内） |

**规则：**
- Gilt 只做"点"，不做"面"——大面积金色会立刻显得廉价。
- 文字可读性：Graphite on Bone 对比度充足；Stone 只用于 ≥14px 的辅助信息，不做正文。按钮用 Graphite 底 + Bone 字。
- 不使用纯黑 `#000` 和纯白 `#FFF`。
- 促销也不用红色；折扣标签用 Graphite 描边 + Dawn 底。

## 3. 字体搭配

| 角色 | 免费方案（Google Fonts） | 付费替代（价格未核实） | 用法 |
|---|---|---|---|
| Display 标题 | **Cormorant Garamond Light / Light Italic** | Canela Light、GT Super Display Light | H1/H2、Logo、包装大字；字号大、字重轻 |
| 正文 | **EB Garamond Regular**（编辑感长文） | Tiempos Text | About 页、品牌故事、礼卡 |
| 细节 / UI | **Jost Light / Regular**（全大写 + 字距 +10%） | Neue Haas Unica、Founders Grotesk | 导航、按钮、价格、标签 |
| 规格数字 | **IBM Plex Mono Light** | Söhne Mono | 规格表（"6.0 MM · 316L · PVD ≥0.5μm"）、包装卡编号 |

**层级示例：** H1 Cormorant Light 56px / 行高 1.1；正文 Jost 16px / 行高 1.6；规格 Plex Mono 12px 全大写字距 0.08em。手机端 H1 降至 36px。

## 4. 摄影风格

**总原则：Morning light, one stone, lots of air.（晨光、一颗石头、大量留白）**

| 维度 | 规定 |
|---|---|
| 光线 | 自然侧光（窗边清晨 7–9 点或 17–18 点）；产品静物用一盏硬光 + 柔光板，制造一个清晰的火彩点；禁用环形灯正面平光 |
| 背景 | Bone 色纸、未上漆的石灰石、亚麻布、旧书页、陶瓷碟；偶尔用一片无花果叶或一枝干燥燕麦 |
| 构图 | 产品占画面 ≤15%；大量留白在上方（给文字留位置）；耳部特写裁到下颌线和颈部，不露全脸或只露半张脸 |
| 微距 | 100mm 微距镜头；每个 SKU 一张"火彩 hero"：焦点在台面，背景虚化成光斑 |
| 模特 | 26–40 岁、多元肤色；素颜感妆容、头发自然向后梳露出耳朵；服装为燕麦、灰、白、海军蓝的针织与亚麻；不用儿童或明显未成年模特 |
| 色调 | 低饱和、偏暖、黑位抬起一点（胶片感）；统一一套 Lightroom 预设 "Lark Dawn" |
| 视频 | 慢速：一束光扫过耳钉 3 秒；手指捏起耳钉对着窗户转动；不加炫光特效（火彩必须真实拍摄） |

**Do / Don't**

| Do | Don't |
|---|---|
| 一张图只讲一件事 | 一张图里放 10 件首饰 |
| 真实皮肤纹理 | 过度磨皮、AI 换脸 |
| 早晨咖啡杯、亚麻床单、窗框阴影 | 海滩、泳池、夜店霓虹 |
| 用实拍展示火彩 | 后期添加星芒/闪光贴纸（会误导消费者） |
| 显示尺寸对比（硬币 / 指尖） | 只拍极近微距让 4mm 看起来像 8mm |

**开箱顺序（Unboxing sequence）**

1. **外层：** 打开信封，看到 Dawn 色薄纸包裹的方形盒子——第一眼是"温柔的晨色"。
2. **封签：** 一枚 Gilt 烫金 L&L 圆形封签，撕开需要一点仪式感。
3. **礼卡：** 抽屉拉开前先看到礼卡："Light, lightly worn." 背面是发音与护理。
4. **抽屉：** 推出抽屉，Graphite 绒面卡槽上一对耳钉，在 Bone 色盒中形成强烈但安静的对比。
5. **光：** 礼卡底部一行小字提示："Take them to the window." ——引导用户在窗边拍第一张火彩照（UGC 触发点）。
6. **绒袋：** 盒底压着一个 Stone 色绒袋，说明 "for travel & a gentle polish"。
7. **之后：** 二维码进入护理页 + 首次评论邀请（7 天后邮件跟进）。

**降本选项：** 若现金紧张，先去掉 tissue（−$0.07）和改用通用绒袋（−$0.08），保留盒子与封签（开箱质感的核心）。组合装（Duet/Trio）共用一个加长盒（双槽/三槽），而不是两三个盒子。
