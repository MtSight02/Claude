## (d) 付费广告

**90 天预算 $4,500 拆分：** W1–4 预热 $300（Meta 线索广告收 waitlist）；W5–8 测试期 $1,600（约 $57/天：Meta $35 + TikTok $22）；W9–13 扩量期 $2,600（约 $74/天，按规则向盈利渠道倾斜）。渠道总体约 Meta 60%（$2,700）/ TikTok 40%（$1,800）。

| 项目 | Meta（FB/IG） | TikTok |
|---|---|---|
| 起步日预算 | $35/天：3 个广告组 × ~$12（ABO） | $22/天：2 个广告组 × $11 |
| 受众 | ① 宽泛：女性 25–44，美国（后加 DE/NL/IE/DK/SE）；② 兴趣：Mejuri、minimalist fashion、COS、Aritzia；③ 再营销：30 天访客 / IG 互动 | ① 宽泛女性 24–40，美国；② 兴趣 Fashion accessories + jewelry；③ 达人 Spark Ads |
| 版位 | Advantage+ 版位，素材以 4:5 和 9:16 为主 | 信息流 |
| 优化目标 | 购买（像素 + CAPI 必须先配好） | 购买（不足 50 次转化/周时先用加购） |

**创意角度（每个角度至少 3 条素材）：**
1. **光（Light）：** 晨光微距，"Catch the first light."
2. **切工（Cut）：** 刻面示意 + 实拍，"More sparkle in less size."
3. **价格反差（Value）：** "The full ear stack for $40."
4. **诚实材质（Honesty）：** "316L steel. Here's exactly what that means."
5. **送礼（Gift）：** 礼盒开箱 + 截单日期。
6. **名字故事（Story）：** "Why we named it after a bird that sings at dawn."

**测试结构：**
- 第 1–2 周（W5–6）：6 个角度 × 2 条素材，统一落地页，找出赢家角度。
- 第 3–4 周（W7–8）：赢家角度下测 5 个不同 Hook（前 3 秒）。
- 第 5 周起（W9+）：赢家素材进入 Advantage+ Shopping（ASC）/ TikTok 优化组扩量；每周补 3–5 条新素材防疲劳。

**Kill / Scale 规则（以盈亏平衡 CPA ≈ $21.5 为基准）：**

| 情况 | 动作 |
|---|---|
| 单条素材花费 ≥ $32（约 1.5× 盈亏 CPA）仍 0 购买 | 关掉 |
| 花费 ≥ $65（约 3× 盈亏 CPA）且 CPA > $30 | 关掉 |
| 链接 CTR < 0.8%（≥ 2,000 次展示后）或视频 3 秒播放率 < 25% | 换 Hook，不加预算 |
| CPA $18–21.5（ROAS 1.77–2.1） | 维持预算，迭代素材 |
| CPA ≤ $18 连续 3 天且 ≥ 3 单 | 每 48–72 小时 +20% 预算 |
| CPA $21.5–25 | 仅在 90 天复购率 ≥ 20% 已被验证时保留（共享模型允许放宽到 $25），否则降预算 |
| 欧盟广告组 | 单独设置更严的 CPA 上限 ≈ €15（欧盟订单贡献利润更低，见 08） |
