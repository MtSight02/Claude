### 创意角度（每个角度至少 3 条素材）

1. **The Wink（产品魔法）**：转头 → 闪光，慢放。
2. **Stack for $40（价值）**：Trio 一次戴齐，价格字幕。
3. **Honest materials（信任）**：316L、PVD ≥0.5μm、检测状态（报告到手后）。
4. **Gift the group chat（社交送礼）**：闺蜜互送、开箱反应。
5. **Desk to date（场景）**：白天 / 夜晚同一副。

### 测试结构

- Meta：1 个 CBO 测试 campaign，3 个广告组（宽泛 / 兴趣 / 再营销），每组 3–5 条素材；每周新增 3 条素材，淘汰最差 3 条。
- TikTok：1 个 campaign，2 个广告组（自有素材 / Spark Ads 达人素材），每组 3–5 条。
- 判断单位：**素材**（creative）优先于受众；只改一个变量。

### Kill / Scale 规则（锚定盈亏平衡 CPA $21.70）

| 情况 | 动作 |
|---|---|
| 单条素材花费 ≥ $22（≈ 1× 盈亏平衡 CPA）且 0 加购 | 关停该素材 |
| 单个广告组花费 ≥ $44（2× CPA）且 0 购买 | 关停广告组 |
| 3 日滚动 CPA ≤ $18（ROAS ≥ 2.1） | 预算 +20%（每 48 小时最多加一次） |
| 3 日滚动 CPA $18 – $21.70 | 保持不动，换新素材观察 |
| 7 日滚动 CPA $21.70 – $26 | 降预算 30%；若 90 天复购率已证实 ≥ 20%，可容忍到 $25（共享文件规则） |
| 7 日滚动 CPA > $26 | 关停 |
| 欧盟广告组 | 盈亏平衡 CPA 更低（约 €16，见 08 号文件），按 €13 作为扩量线 |
