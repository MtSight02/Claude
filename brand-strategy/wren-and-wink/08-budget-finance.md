## 1. 启动预算（三档，按 Wren & Wink 的选择调整）

**相对共享底表的调整逻辑**：
- **品牌设计 ↑**：本名字最大风险是"Wink"滑向廉价，必须在字体、Logo、包装稿上投入更多（斜体 &、鹪鹩封印、火柴盒包装）。
- **摄影/视频 ↑**：品牌核心是"转头闪光"，需要微距与真人转头视频素材。
- **达人 ↑、付费广告 ↓**：社媒原生、Gen-Z 人群，达人素材 + Spark Ads 效率通常高于纯自产广告素材（行业印象，**未核实**）。
- **库存略 ↓**：Café Colors 逐月释放，首批不一次备齐；均价仍按 $2.0/对。
- **包装 Lean 档 ↓**：Lean 档首批省掉邮寄袋内侧印刷与定制绒袋印花。

## 3. 单笔订单贡献利润（Contribution Margin）

### 3.1 基准情景：美国订单，AOV $38（约 1.6 件，沿用共享模型）

| 项目 | 金额 | 占收入比 |
|---|---:|---:|
| 收入（AOV） | $38.00 | 100% |
| 商品到岸成本（1.6 × $3.60） | −$5.76 | 15.2% |
| 3PL 拣货打包 | −$3.50 | 9.2% |
| 尾程运费（满 $35 包邮，我们承担） | −$4.50 | 11.8% |
| 支付手续费（2.9% × 38 + $0.30） | −$1.40 | 3.7% |
| 退货 / 售后损耗预留（3%） | −$1.14 | 3.0% |
| **贡献利润（广告前）** | **$21.70** | **57.1%** |

### 3.2 目标情景：美国订单，AOV $42（约 1.8 件，组合与免邮门槛推动）

| 项目 | 金额 |
|---|---:|
| 收入 | $42.00 |
| 商品到岸成本（1.8 × $3.60） | −$6.48 |
| 3PL | −$3.50 |
| 尾程运费 | −$4.50 |
| 支付手续费（2.9% × 42 + $0.30） | −$1.52 |
| 退货预留（3%） | −$1.26 |
| **贡献利润** | **$24.74**（58.9%） |

> 说明：Encore Trio（$40，3 件）因折扣深、件数多，单笔贡献利润低于同价位的 2 件订单；它的价值在于提高转化与客单件数，需在 Shopify 报表中单独追踪 Trio 订单的贡献利润。

### 3.3 欧盟订单示意：AOV €42（含 VAT）

| 项目 | 金额 | 说明 |
|---|---:|---|
| 含税收入 | €42.00 | |
| 扣除 VAT（按约 20% 平均，DE 19% / FR 20% / NL 21% / IE 23%） | −€7.00 | 净收入 €35.00 |
| 商品到岸成本（1.6 × €3.40） | −€5.44 | 汇率折算，未核实 |
| 3PL | −€3.50 | 欧盟 3PL 报价未核实 |
| 尾程运费（满 €39 包邮） | −€7.00 | 共享区间 €5–9 取中 |
| 支付手续费（按 2.9% + €0.30 保守估） | −€1.52 | |
| 退货预留（3%） | −€1.26 | |
| **贡献利润** | **€16.28** | 约为净收入的 46.5% |

**结论**：欧盟单笔贡献利润明显低于美国（VAT + 更高尾程运费），这就是 06 号文件中前 90 天欧盟广告预算 ≤ 15% 的原因。

## 4. 盈亏平衡 CPA / ROAS

| 情景 | 贡献利润（广告前） | 盈亏平衡首单 CPA | 盈亏平衡 ROAS（= AOV ÷ CPA） | 起步目标 |
|---|---:|---:|---:|---|
| 美国基准 AOV $38 | $21.70 | **$21.70** | **≈ 1.75** | CPA ≤ $18（ROAS ≥ 2.1） |
| 美国目标 AOV $42 | $24.74 | $24.74 | ≈ 1.70 | CPA ≤ $20 |
| 欧盟 AOV €42 | €16.28 | €16.28 | ≈ 2.58（按含税收入） | CPA ≤ €13 |
| 美国单件订单 $24（未达免邮，顾客另付运费） | 约 $10.68 + 顾客所付运费 | 约 $10.7 – $15.6 | ≈ 1.5 – 2.2 | 用购物车加购把单件订单推向 $35+ |

**复购放宽规则**（沿用共享模型）：若 90 天复购率达到 20%，美国首单 CPA 可放宽到 $25。

**广告决策直接引用**：06 号文件的 kill/scale 规则以 $21.70 为基准线、$18 为扩量线、$26 为关停线。

## 6. 敏感性：最值得优化的变量

| 变量变化 | 对每单贡献利润的影响（美国） |
|---|---|
| AOV $38 → $42（组合 + 免邮加购） | +$3.04（$21.70 → $24.74） |
| 包装 $1.10 → $0.70 | 约 +$0.64（1.6 件），但不建议砍"开箱第一眼"组件 |
| 3PL 改为自发货（< 30 单/天） | 约 +$2.0，占用创始人时间 |
| 尾程运费 $4.50 → $5.50 | −$1.00 |
| 关税上调 20 个百分点（示例） | 约 −$0.3 到 −$0.5 |
| 退货率 3% → 6% | 约 −$1.14 |
