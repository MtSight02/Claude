# Wren & Wink · 03 品牌视觉识别

> 视觉总纲：**巴黎文具店 × 老派法式咖啡馆**。像一张奶油色的咖啡馆小票，上面用可可色字写着一句俏皮话，盖了一个樱桃红的小印章。俏皮来自"内容"，体面来自"克制"。

## 1. Logo 方向（3 个）

### 方向 A：Café Wordmark（推荐为主标）

| 项目 | 说明 |
|---|---|
| 字体 | DM Serif Display（Google 免费）做 "Wren" 与 "Wink"；"&" 单独换成同字族或 Playfair Display Italic 的斜体 & |
| 图形 | 无独立图形；"&" 用樱桃红 #A3262E，其余可可色 #3B2A26；在 "Wink" 的 i 点位置换成一个极小的四角星光 ✦（像宝石闪了一下） |
| 版式 | 单行横排，字距 -1% 到 0，大小写混排 "Wren & Wink"；最小使用宽度 80px（网页）/ 18mm（印刷） |
| 为什么 | 斜体 & 是整个品牌的"眨眼"——一个微微倾斜、带点调皮的字符；衬线字体守住精品感；i 点星光把"闪一下"做进字里，克制、不卡通 |
| 护栏 | 星光只能在 i 点位置出现一次；不加阴影、不加渐变、不做弯曲排列 |

### 方向 B：Winking Wren Seal（推荐为辅助标 / 封签）

| 项目 | 说明 |
|---|---|
| 字体 | Gloock（Google 免费）做 "W&W" 合字，或手绘定制 |
| 图形 | 一只极简线描的鹪鹩侧影（尾巴上翘是鹪鹩最可辨认的特征），**眼睛用一颗四角星代替**——这就是"眨眼的鸟" |
| 版式 | 圆形或扇贝边圆形徽章，外圈小字 "WREN & WINK · A LITTLE WINK OF LIGHT"；用于封签、绒袋、社媒头像、网站 favicon |
| 为什么 | 社媒头像在 40px 下仍可识别；扇贝边致敬法式糕点店贴纸与火漆印 |
| 护栏 | 鸟必须是单线条、无填充、无表情；**禁止画成卡通大眼睛或睫毛**——那就滑向低幼区了 |

### 方向 C：Stationery Lockup（备选，偏复古）

| 项目 | 说明 |
|---|---|
| 字体 | 全大写 Playfair Display SC（小型大写），字距 +12% |
| 图形 | 两条细横线夹住名字，下方一行小字 "FIREWORKS-CUT EARRINGS · EST. 2026" |
| 版式 | 居中三行式，像老式信笺抬头或巴黎咖啡馆菜单顶部 |
| 为什么 | 最"安全"、最显贵，适合包装盒盖与发票；但俏皮感最弱 |
| 护栏 | 若选为主标，需在文案与配色上补足性格，否则会被误读为传统珠宝店 |

**建议**：主标 A + 辅助标 B；C 只用于包装内侧和票据。三个方向都遵守 xandy 规则：Logo 写 "&"，域名/账号写 "and"（wrenandwink.com / @wrenandwink，可用性**未核实**）。

**设计交付清单**：主标横版 / 竖版、辅助标、favicon、单色版（可可 / 奶油反白）、最小尺寸规范、安全区（= 字母 W 高度的 50%）、错误示范页。

## 2. 色板

在原方向基础上做了一处补充：新增功能性中性色 **Oat #E6DCCD**，用于边框、分隔线、表单底色，避免直接用灰色破坏暖调。

| 色名 | HEX | 角色 | 使用占比 | 规则 |
|---|---|---|---:|---|
| Cream 奶油 | **#FBF6EE** | 背景主色 | 约 55% | 网站与包装的"纸张色"，不用纯白 #FFFFFF |
| Cocoa 可可 | **#3B2A26** | 主深色：文字、Logo、按钮 | 约 20% | 正文一律用可可色，不用纯黑 |
| Powder 粉雾 | **#E9D3D0** | 柔和辅色：区块底、绒袋、标签 | 约 12% | 大面积使用时搭配可可字，不搭配樱桃字的大段文字 |
| Cherry 樱桃 | **#A3262E** | 点缀：& 符号、价格折扣、CTA 悬停、封签 | ≤ 8% | **全局护栏：任一画面樱桃红 ≤ 10%**；不做大面积樱桃底 |
| Butter 黄油 | **#F1E3B5** | 高光：新品角标、节日横幅、金色款背景 | 约 3% | **永远不用作文字色**（在奶油底上对比度不足） |
| Oat 燕麦（新增） | **#E6DCCD** | 功能中性：边框、分隔线、输入框 | 约 2% | 仅功能用途 |

**对比度提示**（按 WCAG 估算，正式上线前用工具复测）：可可字 / 奶油底、奶油字 / 樱桃底、奶油字 / 可可底均满足 AA 正文要求；黄油色、粉雾色不能作为奶油底上的文字色。

**为什么不廉价**：五个颜色都降了饱和度、带一点灰和暖调；最"甜"的粉被换成 Powder 这种脏粉，最"跳"的红被换成偏棕的樱桃红。避免：荧光粉、薄荷绿、纯正红 #FF0000、紫色渐变。

## 3. 字体搭配

| 用途 | 首选（免费 Google Fonts） | 付费替代（价格**未核实**） | 规则 |
|---|---|---|---|
| 标题 / Logo | **DM Serif Display**（标题）+ Playfair Display Italic（仅 & 与强调词） | Canela、GT Super、Recoleta 等商用授权字体 | 标题句首大写（Sentence case），不全大写大段文字 |
| 备选标题 | Gloock（更有个性、更复古） | — | 用于辅助标与包装 |
| 正文 / UI | **DM Sans**（400 / 500 / 700） | Söhne、Graphik 等 | 正文 16–18px，行高 1.6 |
| 小字标签 | DM Sans 全大写，字距 +8% | — | 只用于 ≤ 4 个词的标签，如 "NEW" "BESTSELLER" |

**排版护栏**：一页最多 2 个字族；不用手写体、泡泡字、圆体；斜体只用于一个词的强调（比如 *wink*），像在句子里眨一下眼。

## 4. 摄影风格

### 4.1 总体

**关键词**：午后咖啡馆窗边的光、近景、皮肤真实、一点点调情的眼神。

| 维度 | 规范 |
|---|---|
| 光线 | 侧窗自然光或模拟窗光（柔光箱 + 硬光点），保留一个"硬光点"让烟花切出火彩；视频必须有一个"转头 → 闪光"的瞬间 |
| 色调 | 暖、微降饱和，阴影偏可可色不偏蓝；整体调色贴近奶油背景 |
| 景别 | 50% 耳部特写（耳垂到下颌线）；25% 半身生活场景（咖啡桌、举杯、拨头发）；25% 静物（产品在奶油纸、大理石咖啡桌、方糖、樱桃旁） |
| 构图 | 耳朵偏离中心，留出文字空间；裁切大胆（只露半张脸、一只眼睛眨眼） |
| 模特 | 18–30 岁成年女性，多肤色、多耳型；真实皮肤纹理，可见耳洞；**避免任何看起来未成年的模特**（CPSIA/定位合规） |
| 道具 | 咖啡杯、樱桃、方糖、旧信封、火柴盒、口红、手写便签；数量 ≤ 3 件 |

### 4.2 Do / Don't

| Do | Don't |
|---|---|
| 一只眼睛微闭的侧脸 + 耳钉闪光 | 夸张的抛媚眼、吐舌头、比剪刀手 |
| 奶油纸 + 一颗樱桃 + 耳钉 | 满桌糖果、彩虹色道具、卡通贴纸 |
| 真实耳朵，有绒毛和细纹也保留 | 过度磨皮、AI 感皮肤 |
| 微距拍刻面，配合刻面示意图 | 加后期星光特效（会被认为造假，也违反真实性原则） |
| 闪光来自真实灯光 | 用滤镜伪造火彩 |
| 金色款配暖肤色光、钢色款配冷一点的晨光 | 混合色温导致金色发绿 |

## 5. 包装设计（成本意识版）

目标：单套包装 **$0.70–$1.30**（落在共享文件 $0.70–$1.60 区间内偏低端），把预算花在"开箱第一眼"上，而不是厚重材料上。所有单价为**估算，未核实**。

| 组件 | 规格 | 估算单价 | 说明 |
|---|---|---:|---|
| 火柴盒式抽拉盒 | 奶油色卡纸，可可色单色印刷，盒盖烫樱桃红小 & | $0.35 – $0.60 | 致敬法式咖啡馆火柴盒；抽拉动作 = 一个小仪式；Trio 用加长款 |
| 耳钉卡 | 可可色卡，奶油字，带烟花切刻面示意线稿 | $0.06 – $0.12 | 背面印材质与护理说明 |
| "小纸条"卡片 | 像咖啡馆小票的窄长卡片，印一句俏皮话 | $0.05 – $0.10 | 每批 4–6 种文案随机放，鼓励拍照分享 |
| 粉雾色棉质束口袋 | Powder #E9D3D0，小号印 W&W 封印标 | $0.15 – $0.30 | 可复用，旅行收纳 |
| 扇贝边封签 | 樱桃红底奶油字，方向 B 徽章 | $0.03 – $0.06 | 仿火漆印效果，**不用真蜡**（成本与运输损坏） |
| 外层邮寄袋 | 可可色纸质气泡袋或硬纸信封 | $0.15 – $0.35 | 外面只印小 logo，内侧印 "Psst — open me first." |
| **合计** | | **约 $0.79 – $1.53** | 量大时取下限；首批可先省掉内侧印刷 |

**合规必印信息**（盒底或耳钉卡背面）：材质 316L stainless steel、制造商名称与地址、欧盟责任人信息（GPSR）、批次号、护理说明。具体格式请与欧盟授权代表确认。

### 开箱顺序（Unboxing Sequence）

1. **邮寄袋**：撕开后内侧可见可可色印字 "Psst — open me first."（第一下会心一笑）
2. **封签**：樱桃红扇贝封签贴在火柴盒抽拉口，需要"拆印"——这是视频里最上镜的 2 秒
3. **抽拉盒**：缓慢推出内盒，盒内底印一行小字 "Turn your head. It winks back."
4. **小纸条**：最上层是一张小票式卡片，随机俏皮话（如 "Certified main character. Receipt attached."）
5. **耳钉卡**：耳钉插在可可色卡片上，卡片上的刻面线稿解释"烟花切"
6. **粉雾袋**：垫在底层，附一张折叠护理卡
7. **结尾彩蛋**：护理卡背面印 "Tag @wrenandwink — we wink back."，引导 UGC

**省钱规则**：礼物包装（gift note + 额外缎带）做成结账页 $3 加购项，而不是每单默认赠送；Trio 共用一个加长盒，比三个独立盒省约 $0.80。

## 6. 视觉护栏总表（防止"Wink"变廉价）

| 风险 | 护栏 |
|---|---|
| 眨眼 emoji 化 | 品牌资产中永不出现 😉 图形；眨眼只用真人或"一只眼 + 星光"的抽象表达 |
| 颜色变甜 | 樱桃红 ≤ 10%；不加入亮粉、荧光色；节日也只在 5 色内变化 |
| 字体变可爱 | 只用衬线 + DM Sans，禁止圆体、泡泡字、手写体 |
| 画面变杂 | 道具 ≤ 3 件，留白 ≥ 30% |
| 特效变假 | 不加后期星光贴纸；闪光必须是真实光线 |
