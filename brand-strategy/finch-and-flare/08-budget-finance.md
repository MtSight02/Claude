## 3. 单笔订单贡献利润（广告前）

### 情景 A · 美国基线订单（与 shared 模型一致，AOV $38，约 1.6 件）

| 项目 | 金额 | 占收入 |
|---|---:|---:|
| 收入（AOV） | $38.00 | 100% |
| 商品到岸成本（1.6 × $3.60） | −$5.76 | 15.2% |
| 3PL 拣货打包 | −$3.50 | 9.2% |
| 尾程运费（满 $35 包邮） | −$4.50 | 11.8% |
| 支付手续费（2.9% + $0.30） | −$1.40 | 3.7% |
| 退货 / 售后预留（3%） | −$1.14 | 3.0% |
| **贡献利润** | **$21.70** | **57.1%** |

### 情景 B · 美国单笔 = The Full Show 金色（$40）

| 项目 | 金额 |
|---|---:|
| 收入 | $40.00 |
| 到岸成本 | −$9.60 |
| 3PL | −$3.50 |
| 尾程运费（包邮） | −$4.50 |
| 支付手续费（2.9% × 40 + 0.30） | −$1.46 |
| 退货预留（3%） | −$1.20 |
| **贡献利润** | **$19.74（49.4%）** |

> **洞察**：Full Show 拉高了客单价，但因为让利深，**单笔贡献利润反而比基线订单低约 $2**。它的价值在"首单转化率"和"后续复购（Afterglow、Halo Huggie）"，所以投放时可以主推，但要盯住整体贡献利润，而不是只看 AOV。若后续数据证明 Full Show 占订单 > 50% 且复购不高，可考虑把 Full Show 的 Huggie 换成更便宜的 The Spark 第二色（仍 $40），或保留价格但取消首单 10% 码叠加。

### 情景 C · 美国单买 The Flare 金色（未达包邮线，向客户收运费 $4.95——**建议值，未核实**）

| 项目 | 金额 |
|---|---:|
| 收入（$24 + 运费 $4.95） | $28.95 |
| 到岸成本 | −$3.60 |
| 3PL | −$3.50 |
| 尾程运费 | −$4.50 |
| 支付手续费（2.9% × 28.95 + 0.30） | −$1.14 |
| 退货预留（3% × $24） | −$0.72 |
| **贡献利润** | **$15.49** |

### 情景 D · 欧盟订单（德国，AOV €42 含 19% VAT）

| 项目 | 金额 |
|---|---:|
| 含税收入 | €42.00 |
| 减 VAT（42 ÷ 1.19） | 净收入 €35.29 |
| 到岸成本（1.6 × 约 €3.30，含到欧盟的头程） | −€5.28 |
| 3PL | −€3.50 |
| 尾程运费（€5–9 区间取中值） | −€7.00 |
| 支付手续费（2.9% × 42 + 0.30，欧盟卡费率**未核实**） | −€1.52 |
| 退货预留（3% × 净收入） | −€1.06 |
| **贡献利润** | **€16.93（占净收入 48.0%）** |

> **洞察**：欧盟订单因 VAT 与更高的尾程运费，单笔贡献利润比美国低约 20%。**欧盟广告必须单独核算**，不能套用美国 CPA 标准。欧盟包邮门槛 €39 不建议再降。

## 4. 盈亏平衡 CPA / ROAS

| 情景 | 贡献利润 | **盈亏平衡 CPA** | **盈亏平衡 ROAS** | 起步目标 |
|---|---:|---:|---:|---|
| A · 美国基线（AOV $38） | $21.70 | **$21.70** | **1.75**（38 ÷ 21.70） | 首单 CPA ≤ $18（ROAS ≥ 2.1） |
| B · Full Show 金色 | $19.74 | $19.74 | 2.03（40 ÷ 19.74） | CPA ≤ $16 |
| C · 单买 Flare 金色 | $15.49 | $15.49 | 1.87（28.95 ÷ 15.49） | 不作为投放主目标 |
| D · 欧盟（德国） | €16.93 | **€16.93** | **2.48**（42 ÷ 16.93，按含税收入） | CPA ≤ €14 |

**规则（与 06 号文件 kill/scale 表一致）**：
- 美国放量线：CPA ≤ $18；关停线：花费 ≥ $32 无单，或 ≥ 3 单后连续 3 天 CPA > $26。
- 90 天复购率 ≥ 20% 时，首单目标 CPA 可放宽到 $25（用复购回本）。
