# Finch & Flare · 03 品牌视觉识别

> 视觉总原则：**"夜色里的一束小烟花"**。大面积 Ivory 与 Ink 构成安静的杂志底色，Champagne 代表金属，Ember 只作为"火花"出现——像一根火柴被划亮的那一点。任何一个页面或物料里，Ember 都应该是你最后才注意到、但一定会注意到的那个点。

---

## 1. Logo：三个方向

### 方向 A · "Spark Ampersand" 火花 &（推荐主标）

| 项目 | 说明 |
|---|---|
| 字体 | 字标用高对比度衬线体。免费：**Cormorant Garamond Medium**（正文字母）+ **Cormorant Garamond Italic** 的 "&"；付费替代：**Canela**（Commercial Type）或 **GT Super Display**（Grilli Type），授权价格均**未核实** |
| 图形 | 斜体 "&" 的末端笔画收成一个**8 芒小星芒**（模拟烟花切从中心放射的刻面），星芒是全 logo 唯一可以用 Ember 的地方 |
| 排版 | 单行横排：`Finch & Flare`，字距 +20；"&" 比两侧字母略小一号、略下沉，形成节奏 |
| 为什么 | ① "&" 是名字的灵魂，也是三个候选名共同的命名规则——把它做成品牌最大的图形资产，未来可以单独作为 favicon、封签、吊牌；② 星芒直接对应主打产品的切工，一眼就讲完故事；③ 衬线体给出"杂志感 / looks expensive"，与快时尚首饰品牌常见的无衬线粗体拉开距离 |
| 延展 | 单独的 "&+星芒" 作为 **monogram**：用于 favicon、社媒头像、火柴盒侧面、封口贴 |

### 方向 B · "The Finch Seal" 雀鸟印章（推荐作为辅助标）

| 项目 | 说明 |
|---|---|
| 字体 | 圆形环绕文字用 **Manrope SemiBold** 全大写、字距 +200：`FINCH & FLARE · SMALL BRIGHT THINGS` |
| 图形 | 一只单线条侧面小雀鸟，**眼睛是一颗多刻面小星**；鸟嘴前方有三根短线表示"迸出的光" |
| 排版 | 直径 1:1 圆形印章，适合烫印、蜡封、贴纸 |
| 为什么 | 给品牌一个"有生命的角色"，适合包装彩蛋、感谢卡、社媒贴纸；但作为主标太具象、缩小后线条会糊，所以只做辅助 |
| 风险 | 鸟类 logo 在市场上较常见，需在 USPTO / EUIPO 做图形检索（**未核实**） |

### 方向 C · "Fuse Line" 引信竖排

| 项目 | 说明 |
|---|---|
| 字体 | **Fraunces**（可变字体，opsz 调到 Display、SOFT 50），付费替代 **Ogg**（Sharp Type，授权价格**未核实**） |
| 图形 | 三行竖排 `Finch / & / Flare`，右侧一根极细竖线（像火柴棍 / 引信）从底部延伸到顶部，顶端一个小 Ember 圆点 |
| 排版 | 竖向构图，适合手机竖屏、吊牌、火柴盒正面 |
| 为什么 | 更现代、更"设计工作室"；竖排在 TikTok/Reels 竖屏片尾卡里表现好 |
| 风险 | 横向场景（网站页眉）需要另做横版，系统复杂度更高 |

### 推荐组合

**主标 = 方向 A；辅助标 = 方向 B 的印章（只用在包装与贴纸）；方向 C 的"引信竖线"作为图形元素借用到视频片尾卡。**
设计交付清单：主标横版 / 主标单色版 / monogram（& 星芒）/ 印章 / 最小使用尺寸（数字端 monogram ≥ 24px，主标 ≥ 96px 宽）/ 安全留白（= "&" 的高度）。

## 2. 色彩系统

### 2.1 色板（含新增 1 色）

| 名称 | HEX | 角色 | 使用占比（全品牌平均） |
|---|---|---|---:|
| **Ivory** | `#F6F1E9` | 主背景、包装托盘、网站底色 | 55% |
| **Ink** | `#1F2433` | 主深色：文字、按钮、火柴盒外套、夜景摄影背景 | 22% |
| **Linen**（新增） | `#ECE4D8` | 次级底色：区块分隔、卡片、商品图背景板、邮件模块底 | 10% |
| **Champagne** | `#D9C3A0` | 金属感辅助色：烫印、细线、Ink 底上的小字、图标 | 6% |
| **Smoke** | `#8A8A8F` | 中性：分隔线、禁用态、大号辅助文字 | 5% |
| **Ember** | `#C8553D` | 点睛：星芒、价格旁的小标签、链接下划线、火柴盒"擦火条" | 2% |
| **合计** | | | **100%** |

> 新增 **Linen** 的理由：只有 Ivory 一种浅底，网站长页面会没有层次；Linen 比 Ivory 深一档，用来区分区块，不引入新的色相。

### 2.2 可访问性对比度（自行按 WCAG 公式估算，请设计时用工具复核）

| 组合 | 估算对比度 | 结论 |
|---|---:|---|
| Ink 文字 / Ivory 底 | 约 13:1 | ✅ 任何字号 |
| Ivory 文字 / Ink 按钮 | 约 13:1 | ✅ **主 CTA 按钮用这个** |
| Champagne 文字 / Ink 底 | 约 9:1 | ✅ 深色区块里的小字 |
| Ember 文字 / Ivory 底 | 约 3.8:1 | ⚠️ 只用于 ≥24px 大字或粗体 ≥19px；不可做正文 |
| 白字 / Ember 按钮 | 约 4.3:1 | ⚠️ 小字号略低于 AA 4.5:1 → **不建议用 Ember 做主按钮** |
| Smoke 文字 / Ivory 底 | 约 3.0:1 | ⚠️ 只做大字、分隔线；**小号辅助文字改用 Ink 72% 不透明度**（约 #5B5D66，≈5.6:1） |

### 2.3 色彩使用规则

1. 一个画面里 Ember 只出现 **一处**。
2. 产品金色由摄影呈现，不要用 Champagne 色块去"模拟金子"。
3. 促销季也不换色：BFCM 用 Ink 底 + Champagne 字 + 一个 Ember 星芒，而不是红黑大字报。
4. 彩锆限定（Afterglow 系列）可在其专属页面临时使用对应宝石色作为照片主色，但 UI 色不变。

## 3. 字体搭配

| 用途 | 首选（免费，Google Fonts） | 备选（免费） | 付费升级（授权价**未核实**） | 规格建议 |
|---|---|---|---|---|
| 展示标题 / Logo / 大字引言 | **Cormorant Garamond** 500 / 600 + Italic | **Fraunces**（opsz Display） | Canela、GT Super Display、Ogg | 只在 ≥ 32px 使用；Cormorant 字形很细，小字号会发虚 |
| UI / 正文 / 按钮 / 价格 | **Manrope** 400 / 500 / 600 | **Inter** | GT America、Neue Haas Unica | 正文 16px / 行高 1.6；按钮 14px 全大写、字距 +8% |
| 数字（价格、规格） | Manrope 的等宽数字（tabular-nums） | Inter tnum | — | 价格统一 `$22` 不带 `.00` |

**字号阶梯（网站，桌面 / 手机）**：H1 64/40 · H2 44/30 · H3 28/22 · 正文 16/16 · 小字 13/13 · 按钮 14/14。

**标志性排版手法**：标题里把一个词换成 Cormorant **斜体**，例如 "Everyday sparkle, *no occasion* required." ——这是品牌"不动声色的幽默"在字体上的体现。

## 4. 摄影风格

### 4.1 三种标准镜头

| 镜头 | 用途 | 光线 | 构图 / 裁切 | 背景 |
|---|---|---|---|---|
| **① The Flare（微距火彩）** | 首页首屏、广告前 3 秒、PDP 第 2 张 | **单点硬光**（LED 点光源或一束透过小孔的阳光），让烟花切的碎光真实迸出；可用慢速转台 | 单只耳钉占画面 60%，45° 俯角；视频：转动 3–5 秒 | Ink 深色布 / 深色哑光卡纸 |
| **② The Ear（耳部佩戴）** | PDP 第 1 张、耳叠图、广告 | 侧窗自然光 + 一盏小点光补"闪"；肤色还原优先 | 3/4 侧脸，裁到耳朵、下颌线、一缕头发；**不露全脸**也可以 | 中性浅色墙、Linen 布 |
| **③ The Still Life（静物）** | 首页故事块、邮件、包装展示 | 柔和日光 + 一处硬阴影 | 火柴盒半开、耳钉放在托盘上；搭配一件"生活小物"（咖啡杯沿、一本书、一根未划的火柴*道具*） | Ivory / Linen 纸面 |

### 4.2 模特

- 年龄 22–35 岁成年人；**不用未成年模特**（与 CPSIA 定位一致）。
- 多样的肤色、耳型、耳洞数量（1 洞到 4 洞都要有），包括有轻微耳垂褶皱的真实耳朵。
- 素人感 > 模特感：头发自然，不做过度修图的"塑料耳朵"。

### 4.3 Do / Don't

| ✅ Do | ❌ Don't |
|---|---|
| 用真实光线让切工自己闪 | **后期加 sparkle 特效 / 星光滤镜**（误导消费者，且评论会翻车） |
| 每张商品图标注尺寸参照（耳垂上的 4/6/8mm 对比图） | 只放白底单图，让人猜大小 |
| 钢色款和金色款各自在对应肤色上拍 | 只拍金色款 |
| 夜景、窗边、黄昏等"有光的时刻" | 海滩、泳池、健身房（那是 Ellie Vail / Pura Vida 的语言） |
| 留白、单一主体 | 一堆首饰堆满画面的"批发感" |
| 保留轻微颗粒感的胶片调色 | 高饱和、HDR 过度锐化 |
| 实拍火柴盒包装开箱 | 用 3D 渲染图冒充实物 |

## 5. 包装

### 5.1 核心概念：火柴盒（The Matchbox）

"Pocket-sized fireworks" 最自然的容器就是**火柴盒**：抽拉式小盒，外套 Ink 色，托盘 Ivory，侧面印一条 Ember 色"擦火条"（纯印刷图案，**不含任何可燃涂层**）。它小、轻（适合信封式寄送，降低尾程运费）、开箱有"划开"的仪式感，也天然适合拍开箱视频。

### 5.2 组件与成本（估算，**未核实**，需 3 家包装厂报价）

| 组件 | 规格建议 | 单价估算 | 省钱技巧 |
|---|---|---:|---|
| 火柴盒（外套 + 抽屉） | 约 70×50×18mm，350g 白卡；外套 Ink 满版印刷 + 主标 Champagne 烫金；抽屉 Ivory 无印 | $0.45 – $0.70 | 烫金只做外套正面一处；抽屉不印 |
| 耳钉插卡 | 抽屉内衬卡，Ivory，印 monogram，开两个插孔 | $0.05 – $0.10 | 与卡片同版拼印 |
| 卡片（Care & Hello） | 名片尺寸双面：正面一句文案，背面保养说明 + QR | $0.08 – $0.15 | 单色 Ink 印刷 |
| 超细纤维袋（兼擦拭布） | 6×8cm，Ink 色，Champagne 单色印 monogram | $0.15 – $0.30 | **一物两用**：收纳袋 + 擦拭布，比丝绒袋便宜且更实用 |
| 封口贴 | 圆形 20mm，Finch Seal 印章图案 | $0.03 – $0.05 | 卷标贴，大批量很便宜 |
| **单件合计** | | **$0.76 – $1.30** | 目标值 $1.10，与 shared 财务模型一致 |
| 套装盒（Duet / Full Show） | 加宽版火柴盒（双 / 三抽屉横排） | $0.90 – $1.60 | 只做一种加宽规格，Duet 留空位放卡片 |
| 外寄信封（每单） | Ink 色纸质气泡信封或小型邮寄盒 | $0.25 – $0.50 | 通常由 3PL 包材费覆盖，注意对账 |

**欧盟合规信息位**：抽屉底部贴一张小标签——制造商名称与地址、欧盟责任人名称与地址、批次号（GPSR 可追溯）。这是合规要求，也给人"认真"的感觉。

### 5.3 开箱流程（一步一步）

| 步骤 | 客户看到 / 做的 | 设计意图 |
|---|---|---|
| 1 | 收到 Ink 色信封，正面只有一个 Champagne 的 "&+星芒" 和一个 Ember 小贴（"Handle with delight."） | 第一眼就"不像便宜货" |
| 2 | 撕开信封，Ivory 衬纸包着火柴盒，封口贴是 Finch Seal 印章 | 撕封口 = 小仪式，适合拍视频 |
| 3 | 火柴盒外套背面一行小字：*"Contains one small fireworks show. No matches included."* | 品牌幽默的第一次出现 |
| 4 | 推开抽屉：耳钉插在 Ivory 内衬卡上，正对开口方向，第一眼就是切面的闪光 | **光是第一主角** |
| 5 | 抽屉里叠放卡片：正面 *"Wear them on a Tuesday."*；背面保养 3 条 + QR（链接到 Ear Map 耳叠搭配页与评价页） | 引导复购和留评 |
| 6 | 最下层：超细纤维袋，卡片提示 *"This pouch doubles as a polishing cloth."* | 实用的惊喜，降低售后 |
| 7 | （仅套装 / 首单）多一张手写感印刷卡：*"First light — thank you for being early."* | 首批客户的归属感，鼓励 UGC |

### 5.4 包装的"不要"

- 不印"环保 / 可回收 / 可降解"等字样，除非包装厂提供材料证明（红线第 7 条）。
- 不要用磁吸硬盒：单价高（常见 $1.5+，**未核实**）、体积大、运费高。
- 不要在火柴盒上写任何"strike here"之类可能被误解为真的火柴的指引。
