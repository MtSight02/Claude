## 2. 单件成本（Landed Cost）模板

以 **6mm 烟花切金色款（H6-G，$24）** 为例：

| 成本项 | 假设值 | 计算 |
|---|---:|---|
| 出厂价（含 PVD 镀金） | $1.60 | 供应商报价 |
| 包装分摊（盒 + 卡 + 袋） | $1.10 | 包装总价 ÷ 数量 |
| 头程 + 关税分摊 | $0.90 | （运费 + 关税）÷ 数量 |
| **到岸成本 Landed Cost** | **$3.60** | |
| 售价 | $24.00 | |
| **产品毛利率** | **85.0%** | (24 − 3.6) ÷ 24 |

> 珠宝 DTC 产品毛利率 80%+ 很常见，但**真正决定生死的是"单笔订单贡献利润"和获客成本**。

## 3. 单笔订单贡献利润（Contribution Margin）

假设平均客单价 AOV = **$38**（约 1.6 件），美国订单：

| 项目 | 金额 | 占比 |
|---|---:|---:|
| 收入（AOV） | $38.00 | 100% |
| 商品到岸成本（1.6 件 × $3.60） | −$5.76 | 15.2% |
| 3PL 拣货打包 | −$3.50 | 9.2% |
| 尾程运费（满 $35 包邮，由我们承担） | −$4.50 | 11.8% |
| 支付手续费（2.9% + $0.30） | −$1.40 | 3.7% |
| 退货 / 售后损耗预留（3%） | −$1.14 | 3.0% |
| **贡献利润（广告前）** | **$21.70** | **57.1%** |

**由此推出的广告红线：**
- **盈亏平衡 CPA（首单）= $21.70**；盈亏平衡 ROAS = 38 ÷ 21.70 ≈ **1.75**。
- 起步期目标：首单 CPA ≤ $18（ROAS ≥ 2.1），允许测试期短暂亏损。
- 若 90 天复购率达到 20%，可把首单 CPA 放宽到 $25（用复购回本）。

## 4. 敏感性：哪些变量最值得优化

| 变量变化 | 对每单贡献利润的影响 |
|---|---|
| AOV 从 $38 → $44（多卖一件 4mm 小钉） | 约 +$4.5 |
| 包邮门槛从 $35 提到 $39 | 推高 AOV，但可能降低转化，需 A/B |
| 3PL 换成自发货（初期 < 30 单/天时） | 约 +$2.0，但占用创始人时间 |
| 包装从 $1.10 降到 $0.70 | +$0.64（但小心损伤开箱质感——这是品牌溢价来源） |
| 关税上调 20 个百分点（示例） | 约 −$0.3 到 −$0.5 / 单（产品出厂价低，冲击相对有限） |

## 5. 回本测算（标准版）

- 前 90 天总投入 $24,000，其中可变现库存约 2,500 对。
- 若 90 天售出 900 单 × $38 = $34,200 收入，贡献利润 900 × $21.70 = $19,530，减去广告 $4,500 与达人 $2,000 → 约 $13,000 回收（**示意**）。
- 剩余库存（约 1,060 对）是下一季的周转基础。

> 关键指标看板（每周）：会话数、转化率（目标 2.0–3.0%）、AOV、首单 CPA、退货率、邮件订阅率（目标 3–5% 访客）、复购率。
